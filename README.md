Задача. Напишите программу для выбора строк по указанным критериям.
Формат ввода:
Из sys.stdin вводятся строки слов, записанных через пробел.
Формат вывода:
Введённые строки нужно разбить по три (если число строк на три не делится, последние 1 или 2 не
учитываются).
Для каждой тройки строк нужно выбрать слова, длина которых имеет такую же чётность, как и
суммарная длина всех трёх строк.
Удалить повторения и отсортировать (оба действия без учёта регистра).
Вывести первые 5 слов или все, если их меньше, через точку и пробел с большой буквы.

Nanny Ogg had seen a lot of strange things
some of them even twice

Once an entire house fell on her head
But she had never seen
Granny Weatherwax rouged
